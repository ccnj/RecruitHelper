# 智联 IM 页面驱动巡检事实记录

日期：2026-07-25

用途：[`0725当日计划-页面驱动聊天巡检与采集恢复.md`](0725当日计划-页面驱动聊天巡检与采集恢复.md) 批次零事实门

数据纪律：本文只记录结构、数量、类型与布尔结论，不记录候选人姓名、正文或平台原始身份。

## 一、真机现场

在当前已登录智联账号的 `/app/im` 页面完成只读观察与一次可逆的会话行打开：

1. 会话列表唯一滚动根为 `.im-session-list__virtual`，行容器使用
   `div[role="listitem"]`，业务行根为 `.im-session-item`；
2. 初始已加载 20 条业务行，当前视口实际相交约 7 条。已加载集合和当前视口
   不是同一个概念；
3. 行内公开 DOM 能观察到未读角标、职位、最后消息预览和活动时间，但没有
   `href`、`data-*` 或其他公开标准属性直接携带完整 `conversationRef`；
4. 打开一条行后，路由从 `/app/im` 变为
   `/app/im?sessionId=<opaque>`。本次观察到的 `sessionId` 为 32 位字母数字
   不透明标识；页面同时恰有一条业务行进入选中态；
5. 打开行后列表行数与滚动位置保持不变，说明当前行可以在同一列表现场完成
   “打开 → 路由身份回读”；
6. 向下滚动到当前已加载集合底部后，页面异步把业务行从 20 条扩展到 31 条。
   扩展不是固定延迟完成，须以行集合和滚动几何稳定为就绪条件；
7. 初始注入状态只覆盖首批 20 条。懒加载后的新增行不能按 DOM 序号与初始
   状态强行配对，也不能按姓名、职位、头像或消息预览猜身份；
8. 会话行打开可能产生已读等平台侵入，因此正式路径仍沿用既有 intrusive
   分类、取消屏障和账号复核。

## 二、旧项目考古结论

旧项目使用相同的会话列表与 `role=listitem` 结构，并按页面顺序处理后继续
滚动。该实现只证明“页面驱动”是已有业务经验，不构成当前页面事实。旧实现里
按 `resumeNumber`、姓名或最近消息兜底的候选方案不进入新项目。

## 三、对本轮实现的约束

1. `chat.readList@1` 与 `chat.readThread@1` 的现有契约形状足够，不新增原语、
   窗口 token 或手侧持久状态；
2. 列表每次只交付一个当前稳定窗口，并如实保留 `complete/nextCursor` 语义；
   脑必须在取得该窗口后立即按页面顺序判断和处理，不能先聚合完多页再回头
   打开第一窗目标；
3. 会话身份由当前窗口的页面运行时数据与打开后的路由共同确认。任何一步
   缺失、不唯一或重排都结束本轮，不降级按姓名、位置或模糊文本定位；
4. `chat.readThread` 的定位器只检查当前窗口，不回顶部、不滚动全表；
5. 当前路由已打开后，历史读取不得再用 `getSessions` 全局扫描寻找会话；
6. 页面 API 的 10 秒截止需由插件内局部超时和自动化测试证明。事实门不通过
   故意挂死真实页面来制造样本。

## 四、事实门结论

**通过。** 当前页面具备“当前稳定窗口 → 唯一行 → 打开 → 路由身份回读”的
最窄生产路径；实现必须逐窗口交错处理，并删除两处全局找人行为。

## 五、2026-07-26 运行事实补充

后续真实巡检暴露出一处实现偏差：`chat.readList` 的主路径实际读取
`getSessions` 独立分页，而 `chat.readThread` 只允许定位当前虚拟列表已经加载
的行。于是列表能返回当前页面尚不能定位的会话，表现为连续
`TARGET_NOT_FOUND`；发送或打开会话造成列表重排后，旧分页游标还会表现为
`CURSOR_INVALID`。这不是候选人业务状态异常，而是两套列表世界不一致。

据此收窄实现边界：

1. `chat.readList` 和 `chat.readThread` 字面复用同一份当前 DOM/Vue 窗口读取器，
   不再用独立 API 分页或启动快照制造导航目标；
2. 每份窗口快照最多打开一个需要读线程的会话；打开、已读、回复或卡片动作后
   立即丢弃旧窗口与游标，最短轮次间隔后从当前页面重新读取；
3. 目标在点击前离开窗口、列表采样不稳定或游标因重排失效，都按“本轮快照
   过期”正常收束，不登记人工静默、不从数据库反向全表找人，也不把它解释成
   发送失败；
4. 页面可见滚动继续遵守至少一秒并带小幅随机抖动的交互节奏。
5. 懒加载后的窗口若保留此前已加载前缀，只交付稳定重叠边界之后的新增后缀；
   重叠不连续则丢弃本轮游标重读。到达当前可见底部时只代表本轮页面扫描自然
   收束，不代表平台历史永久穷尽；它不得触发人工暂停，后续正常巡检仍从新鲜
   页面窗口开始。
