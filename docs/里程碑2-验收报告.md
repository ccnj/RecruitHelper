### 3.1 正式 M2 Node 端到端

该 harness 不调用 M2 的 `/admin/cmd` 调试入口，剧本为：

`本地 hello/welcome → 绑定前 probe → 账号绑定 → 今日开启 → pageAbsent → ensureSurface → 再 probe → readList → 建索引 → 人工标 tracked → 等生产 60 秒最小轮间隔 → readThread → 首次收编`

验收结果：

- 四条 M2 原语均由账号 actor 生产，经正式 Dispatcher、真 WebSocket 和生产插件 Dispatcher 执行，命令账本终局均为 `ok`；
- 首次启动由手本地生成稳定 `handId`，无需用户配对；握手报文无 auth/issued，合同摘要不同只产生告警；
- 绑定前只有 `probe.platform` 可省略 account context；绑定后 actor 的 probe 携带完整 context；
- 首次收编保存两条 fixture 历史并建立 adopted boundary，本轮新增投影为 0；
- M2 阶段 `/admin/cmd` 调用数为 0，测试与生产使用同一代码路径；
- debug 三原语回归仍通过。

### 3.2 关键确定性故障覆盖

- SQLite 单连接事务回调不得重入 Store；result、processed witness 和命令终局同事务回滚。
- 逻辑 replacement chain 的订阅者按引用计数释放，不泄漏等待者。
- result 失败按 5 秒、15 秒重新派发，旧物理命令先持久化终局再唤醒逻辑等待者。
- 巡检跨午夜不使用旧观察继续派发；长命令期间人工事件可更新静默窗并阻止下一条 intrusive 命令。
- 重复快照、连续相同文本、窗口切边、迟到快照、零重叠、卡片状态跃迁和首次收编均有表驱动测试。
- 固定 seed 的 20,000 场景同文边界长跑直接调用生产 `Reconcile`：覆盖 298,540 条消息、227,331 条主重复文本、9,440 个歧义和 4,536 次追加后复读。长跑先发现“完整迟到旧窗口与短后缀偶合时误投影”的反例，现已改为保守 `stale`、零投影并写歧义审计；修复后无超额或重复投影。
- 卡片跃迁与 `Message.CardState` 在同一 SQLite 事务写入 append-only outbox；测试覆盖重启后 pending 仅一条、重复对账不增生、显式 ack 幂等且保留事实、强制 outbox 写失败时卡状态/新消息/会话尾/轮计数整单回滚。
- 主进程收到退出信号后先 cancel，再有界等待 actor/event/health/fault 循环收束。
- 真机用户点击事件在一轮长 `chat.readList` 途中到达后，脑建立静默窗并在列表结束时拒绝继续派发 `chat.readThread`；该轮唯一终局为 `USER_ACTIVE`，账本没有变化。

## 5. 已知残余风险

以下未销项按“影响、止损、再次验证触发条件”登记；它们不能被旧项目资料或单元 fixture 冒充真机事实：

| 未销风险 | 影响 | 当前止损 | 再次验证触发条件 |
|---|---|---|---|
| 没有第二个智联真实账号 | 尚不能真机证明切号后 fingerprint 必变 | 任一身份字段变化、摘要不符或不可观测即停止 intrusive 命令并要求真人重绑 | 获得第二个可控智联账号或独立测试 profile |
| 未实际登出当前生产账号 | 登录失效后的页面具体形态仍可能变化 | `loginState=out`、fingerprint 缺失或 content script 持续失活均暂停 actor；不自动登录 | 有可恢复的专用测试账号，或业务方允许演练登出/重登 |
| 没有可控的“接受换微信卡片”样本 | 数字状态到 accepted/rejected 的映射尚不能确证 | 数字状态一律保留 `unknown`，不触发确定性状态推进 | 历史中出现可核样本或候选人配合操作 |
| 图片、语音、文件未逐类取样 | 未知媒体可能只保留系统摘要，无法宣称完整语义 | 未知类型保守归 `system`；缺方向或稳定身份则响亮失败 | tracked 会话自然出现对应媒体样本 |
| 完整线程只有 7 条，尚无 50/500 条线程样本 | 极长线程的实际时长、跨页边界与载荷分布仍无真机量化 | 每页最多 64 条、结果 64 KiB 硬门禁、opaque cursor；超限或无稳定游标响亮失败 | 获得 ≥50/≥500 条且许可读取的真实 tracked 会话 |
| 连续同文恰落跨页边界缺真实页面长线程样本 | 20,000 场景生产算法长跑已覆盖多解并修过反例，但真实平台窗口分布仍可能不同；不承诺无条件零漏 | 手保留完整候选；完整旧窗口优先 `stale`，其余由脑按最小新增裁决并写审计；不自动发送 | 自然出现重复同文长线程，或专门构造可控真实历史样本 |
| 第二平台没有账号 | 无法做第二平台真机实现与验证 | 明确不开发第二平台；脑端生产代码保持平台无关 | 用户提供该平台真实测试账号后另开里程碑 |

实际登出会改变当前真实账号的认证状态，不属于 `docs/真实账号测试授权记录.md` 已授权的聊天测试范围，也可能在无法恢复凭据时中断用户工作。因此本里程碑不擅自执行登出；登录失效的确定性处理由生产错误门禁与自动化覆盖，并把真实页面形态按上表保留为显式残余风险。这是授权边界裁决，不是把登录态假定为永远有效。
