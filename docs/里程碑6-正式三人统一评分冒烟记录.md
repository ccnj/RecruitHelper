1. 对同一 `batchId` 再次调用统一评分，管理结果仍为 `3/3 completed`，评分 invocation 总数保持 3，没有新增 provider 调用授权。
2. store 回归覆盖同 revision 的其他批次、`batchId=NULL` 历史行和未完成批次；它们均不能进入目标批次评分。
3. 合成集成测试覆盖“1 成功 + 1 provider 失败 + 1 非法输出”，三人仍全部终局，重复运行不再调用 provider，且 hand 命令数不变。
4. 启动恢复会把崩溃遗留评分预留写成 `transportFailed + processInterrupted`，不重调 provider。
5. 独立阻断级审查未发现跨批、二次调用、触碰手、进入筛选/发送或管理响应泄漏路径。
