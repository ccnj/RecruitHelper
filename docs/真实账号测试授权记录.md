> 本文只记录项目测试环境与业务侧许可，不记录账号、Cookie、token、候选人身份或聊天内容。

## 当前有效授权

- 记录时间：2026-07-17（Asia/Shanghai）。
- 事实来源：用户在 Codex 任务中的明确陈述。
- 当前用户的 Chrome 已登录一个可供 RecruitHelper 开发与验收使用的**智联招聘真实账号**。
- 用户确认其老板已同意在该账号上开展真实页面测试，包括向真实候选人发送招呼、聊天消息，以及完成本项目验证所需的其他候选人可见操作。
- “其他候选人可见操作”不包含修改账号设置、发布或删除职位、删除业务数据、购买/付费、批量导出数据等实质不同的操作；这些动作如未来确有需要，须另行确认。
- 测试产生的候选人沟通与业务善后由老板负责；RecruitHelper 当前不承担自动清理这些测试痕迹的任务。
- 在上述项目测试范围内，后续执行常规打招呼、聊天等真机测试**不需要逐条重新确认许可**。
- 当前没有其他招聘平台的可用测试账号，因此本授权不扩展到其他平台或其他账号；第二平台开发等具备真实账号和真机验证条件后再启动。

## 工程边界

这项授权解决的是“能否在真实账号上制造外部效果”的业务许可问题，不改变系统的正确性与故障安全纪律：

1. M2 的产品范围仍是智联感知与同步；人工在页面上发送消息可以制造增量样本，但不能冒充 `chat.send*` 原语已经验收。
2. 真实 effectful 原语进入 `[X]` 批次时，仍须经唯一命令通道，并同批具备确定性幂等键、journal/outbox、guards、后置条件证据和配套验证读。
3. 结果未知、核验失败或无法排除副作用时，不得因“测试已获授权”而自动再发；必须进入 suspect，由人工裁决。
4. 真机出现账号不符、登录失效、验证码、风控提示、平台限制或未知付费动作时，暂停该路径并报告；这属于环境或范围变化，不属于日常聊天测试许可。
5. 提交到仓库的页面样本、截图和日志必须脱敏；不得提交 Cookie、token、手机号、微信号、候选人姓名或可还原身份的聊天正文。
6. Chrome 切换到另一个智联账号，或当前账号身份无法与脑侧绑定确证时，本授权对应的自动化绑定立即失效；重新确认前不得执行 intrusive/effectful 命令或候选人可见动作。

## 变更规则

账号、授权人、允许动作范围或善后责任发生变化时更新本文；未更新前不得把本授权外推到新账号或新平台。
