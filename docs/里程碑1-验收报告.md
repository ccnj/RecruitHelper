## 真机人眼验证(2026-07-17,甲方亲验)

在真实 macOS Chrome 147 加载 `plugin/dist` + Electron 客户端,亲眼确认闭环:
插件 SW 启动→连上→配对(hand-01 在线)→点 switchWindow→标签页切换→账本 attempt=1/ok→
帧观测台干净的 cmd/ack/result/ack + ping/pong 心跳。**"SW 生死"与"可视渲染"两条尾巴消除。**

真机逼出并修复的两个真 bug(Node 测试与编译都测不到,正是人眼验证的价值):
- **白屏**:Vite 默认 base=/ 打出绝对路径资源,Electron file:// 解析到磁盘根 → 空白。修 `base:'./'`(提交见 git log)。
- **supersede 重连风暴**:被顶替的孤儿 socket 迟到 onclose 置空 this.ws 并触发重连 → 与顶替者 ping-pong(几秒 171 次)。修:WS 陈旧处理器守卫 + 换连接前关旧 + SUPERSEDED 退避。
