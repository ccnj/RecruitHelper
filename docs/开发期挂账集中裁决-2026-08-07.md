# 开发期挂账集中裁决(2026-08-07)

## 背景

2026-08-07 对 AGENTS.md 做结构清理(批次一:开篇云端出站去重,合并节点 402611c)时,盘点出十项以"首个真实客户交付"为触发点的挂账义务,并暴露一处事实矛盾:悬置决策规定契约 append-only 冻结点为"第一次给真实客户装插件之时",而客户机已装插件并在真实运行,按字面触发点已过、冻结事件却未记录。甲方当日经提问卡逐项确认,本文件如实记录全部裁决,作为同批 AGENTS.md 修订的唯一授权源。

## 裁决

**一、首客认定。** 甲方原话:"目前少量交付,仍可视为开发阶段。"当前客户机的少量交付不构成"首个真实客户交付";产品形态基本定型,不会大改。

**二、冒烟冲刺临时剖面:整章删除。** 提问卡初答为"转正为常态"(自动发送、CC 事后审查、无逐条确认即正式产品形态);甲方随后明确"已不是冒烟冲刺阶段,产品功能基本开发完了,段落直接删"。执行方验证章内仍在生效的法条归属后,按"有家随章删、无家迁入"执行:

- 多气泡逐项独立安全轨、插话照发完、拒绝挽留气泡边界、换微信承接例外:《沟通逻辑规格-v4》112/114/116/118 行已有更完整的正式表述,随章删除,不另复制。
- "任何仓库文档不得出现候选人 PII":全仓无第二落点,迁入 AGENTS.md 全局约定独立条目。
- 拒绝正则族、RSM-01/02 与 SR-01/02/04 启用与优先级、177/259/313 探针门、343 保守分支,以及 2026-07-22 撤销"每日 30 条上限"与"全局风控熔断"的记录:迁入全局约定「沟通分类启用边界与配额闸撤销」条目。
- 冲刺框架(最高优先级、临时覆盖、首客前显式退出义务)随裁决作废删除。自动发送、无逐条确认、CC 每日事后审查即正式产品形态,授权以本文件为记录。

**三、三个上报与客户知情授权。** 现场数据上报、工作状态上报、日志上报全部保留现状,不设客户知情或授权环节;现场上报服务器留存 14 天、工作状态明细 90 天滚动清理照旧;日志上报维持常开、无开关、载荷照旧。现场与日志两条的"必答项"就此结案。

**四、开发期工具四件保留现状进客户环境。** ai-traces.db 原文库(无限期保留、不加密、无开关)、`RECRUITHELPER_DEV_ALLOW_OUT_OF_WINDOW` 环境变量入口、开发者 SQL 控制台、开发者诊断台明文边界,均原样保留,客户环境不移除、不加锁。

**五、契约 append-only 冻结点改触发。** 截止点由"第一次给真实客户装插件之时"改为"甲方显式宣布结束开发阶段之时";当前少量交付定性为开发阶段,不触发冻结,契约继续允许破坏性修订。发生时以 commit/tag/日期记录冻结事件的义务不变。

**六、expectedTail 观测闸复核义务撤销。** "首客前必须复核一次"义务撤销;比对与观测记录永续保留,存废需要时依观测数据另行裁决。
