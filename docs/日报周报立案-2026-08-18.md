# 日报周报立案（2026-08-18 甲方裁决）

本文固化 2026-08-18 甲方与执行方逐项谈定的日报/周报需求与裁决理由。规范条款见 `AGENTS.md`「全局约定·运营通知 webhook」的「每日日报」段与「全局约定·运营周报推送」条目；本文是决策底稿，条款与本文冲突时以 AGENTS.md 为准。

## 1. 定位：给客户看的交付物台账

两份报表经既有链路送达客户：webhook 机器人发我方企微内部群，安卓真机按正文中的客户名转发到对应外部客户群。因此它们是**服务成果的展示物**，不是内部诊断面：

- **只展示交付物，不展示过程量与负向指标。** 成果字段仅换微信、约面两项。招呼数与回复数是分母——客户会用它算转化率并产生质疑，不报；拒绝、拉黑、失败、待人工不报。内部监控继续用管理后台运行状态单客户页，那里 13 列口径齐全，两个出口各司其职。
- **零也照发，格式与非零完全一致。** 甲方取向是台账感而非喜报感：天天准点到、格式恒定的报表读起来像如实记账，零就是零，比"有成果才发"更可信，也保住"系统每天在干活"的打卡感。待面试名单为空时固定写「暂无」，同理。
- **不带环比。** 下跌环比是在客户面前自曝，甲方裁决整个不要（曾候选"只报涨不报跌"方案，弃）。
- **不带独立日期行。**"昨日成果"三字自明，单独日期行无效信息。2026-08-19 甲方修订：「昨日成果」段头括注数据所属日期（如"昨日成果(08-18)"）——日报到达时间浮动（晚开机、真机转发延迟），括注钉死数字归属，与独立日期行（说"消息哪天发的"）语义不同。

## 2. 分工：日报客户端发，周报旧后台发

- **日报由各客户端发**：待面试名单（姓名、职位、面试时间、方式）只存在于客户机本地库，后台没有也不该有（工作状态上报载荷明令不含候选人身份）。计数与名单都本地现算，经既有运营通知发件箱走同一 webhook。
- **周报由旧后台发**：纯计数可从既有工作状态上报数据算出（每机每日最后快照、跨机相加，与运行状态单客户页同口径，按客户端 local_date 切上一自然周），周一准点不依赖任何客户机开机。周报因此**永远不含候选人名单**；若未来要周报带名单，需重谈形态。

## 3. 错峰送达（槽位）

动机：转发真机在同一分钟收多条会连发触发微信风控；错开后到达时间有人味；周一早上日报批（8:30 段）与周报批（9:00 段）隔开，客户群里两条汇报不背靠背。

- **日报槽位 = 本地 08:30 + 客户id 分钟。** 客户 id 是旧后台自增主键，bind 响应已下发并存于本机配置，零后台改动即可取到；生产现状 11 个客户、id 1–13，槽位落 8:31–8:43，缺号（已删客户）空一分钟无害。开机早于槽位则准点发；晚于槽位随到随发（约开机一分钟内），不设当日截止，隔日不补。在线即发，不要求已开始业务——绑定"开始任务"会让到达时间取决于运营点按钮的时刻，槽位名存实亡。
- **周报 = 服务端 09:00 起按客户 id 升序每条间隔约 60 秒**，单进程循环天然精确，次序与日报一致。
- 远期客户 id 超过 30 会漂进 9:00 段，届时再改基准，现在不加机制。

## 4. 口径一致性（甲方知情的采样时点差异）

两报使用同一套计数实现与同一日界（本地 00:00），但采样时点不同：日报是次日早晨**重算完整昨日**，周报取**当日最后一份 5 分钟快照**。差异仅来自快照后到停机前的分钟尾巴、以及候选人夜间回复次日被读到（按消息实际时间计入昨日）。方向恒为日报 ≥ 周报，日报更准。甲方 2026-08-18 认可该差异，不为消除它让客户端本地存快照。

## 5. 已知边界（记录级，均不加机制）

- 已约面后被平台拉黑的候选人 main_status 仍为 interviewed，待面试名单分辨不出、会照常列出。
- 换到微信后口头约定的面试系统看不见，名单只含平台邀面卡约成的。
- 同一客户多台机器各发各机日报（现网全部单机）。
- 客户端整日未开机则当日日报缺席；上周零上报的客户不发周报。
- 消息为企微 text 格式，2048 字节上限，超长按现有截断逻辑收尾（现状字段量远不及上限）。

## 6. 验收口径（出口）

1. 条款修订独立先行 commit（本文同批）。
2. 客户端日报全链路本机真发一条进运营群，格式与数字人眼核对。
3. 旧后台周报在生产数据上经一次性脚本手动触发真发一条，核对同上。
4. 客户端发版、旧后台部署（含 `WEEKLY_REPORT_WEBHOOK_URL` 环境变量；重启 console-server 的旧客户中断风险为既有知情接受）。

阻断线：报表正文不得进入普通日志/审计（只进 webhook）；周报载荷零候选人信息（独立结构体拼装）；发件箱新类型不得影响既有换微信/约面通知与 2 小时并发窗口；日报全链路只读旁路，任何失败不阻塞业务。
