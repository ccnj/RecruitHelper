## 一、脑侧零改动的依据（读 `events.go` / `reconcile.go` / `effect_verifier.go`）

- 出站 `card/interviewInvite` 任一状态 → `EventInterviewInvited`；入站 `accepted` → `EventInterviewAccepted`；意图 ok 收编把账本行写成 `cardState=unknown`。
- **同一 `sourceKey` 跨轮读回 cardState 不同会被当卡片跃迁**（`forwardCardTransition`：unknown→pending 算前进），而邀面卡跃迁只认 accepted/rejected，其余 `unknownEvent` 转人工。所以 BOSS 出站卡必须**投 unknown**（与智联同构），见 2.1。
- 验证器（1.1 分支）：`interview` 缺席时只看方向、类型、派发窗口、常量哈希。

### 2.2 `chat.sendInviteCard(conversationRef, interview{startsAt, endsAt?, method})`

**参数换算（纯函数，单测钉）**：`startsAt` 按本机时区拆成 `YYYY-MM-DD`、`HH`、`mm`；`endsAt` 同法。
- `onsite`：走「线下面试」+ **精准时间**单点（`HH:mm`），要求 `mm` ∈ {00,05,…,55}、`HH` ∈ 08–20。
- `wechatVideo`：走「线上面试」+ 面试平台「微信视频」+ **宽松时间**起止（`HH:mm-HH:mm`），要求两端 30 分钟格、开始 08:00–20:00、结束 09:00–21:00、结束 ≥ 开始+1 小时。
- 日期必须 ≥ 今天；所在月为日历当前月或下一月（`.next` 一次；再远 → 干净失败）。
- 任一不合格 → `GUARD_FAILED`、retryable=no、detail 留实际值，**不取整、不改时间**（少做方向）。脑侧 canonical 时段是整点起 1 小时格，正常全部合格。

**前置**（世界状态核对）：目标绑定（`ensureBossSendTarget`）；`bothTalked=true`；工具栏「约面试」文本恰为「约面试」（「查看面试」→ 已有面试，干净失败 no）；消息数组无出站 21130009 行。

**动作序列**（每步 `osClick` 后条件轮询后置，封顶 60 秒；任一步不就绪 → 点「取消」收回模态后按 retryable 失败）：
1. 点「约面试」→ 等 `.interview-invite-dialog-ui` 且 `.dialog-wrap.active`。
2. 面试类型：`wechatVideo` 点「线上面试」→ 等该 label 带 `.radio-checked` 且标题「线上面试邀请」；`onsite` 保持「线下面试」（若不是则点回）→ 地址输入非空（空 → `manualOnly`，平台未配地址）。
3. `wechatVideo`：点 `.meetingtype-select` → 等 `.ui-select-visible` → 点 `li.ui-select-item`「微信视频」→ 等选中文本「微信视频」。
4. 日期：点日期框 → 等 `.ui-datepicker-visible`；需要时点 `.next` 一次并等月份文案变；点 `span.cell.day` 文本 = 日（今天的格文本是「今」）→ 等 value = `YYYY-MM-DD`。
5. 时间：点时间框 → 等 `.dropdown-menu-open`；`onsite` 保持「精准时间」，点小时、点分钟 → 等 value = `HH:mm`；`wechatVideo` 点「宽松时间」→ 等 `.selected` → 点开始 → 等 `.selected` 与结束列重过滤 → 点结束 → 等 value = `HH:mm-HH:mm`。**列表项在可视区外时先 `osScroll` 该 `ul.time-select-ul`**（li 44px，一屏 4 项半；滚轮注入生产首用）。
6. **最后一道闸**（同一 evaluator 复核）：模态仍在、radio、平台文本、日期 value、时间 value 逐字等于期望、选中行=目标会话、「发送」在原位。缺一 → 点「取消」→ 失败。
7. 证词 attempting → `osClick`「发送」→ 至多一次。

**正证**：轮询读消息数组，新增出站 21130009 行、`time` 不早于派发 → ok：`sourceKey=mid`、`contentHash=sha256("card\x1finterviewInvite")`、`interview` 原样回显 args、`tsApprox=time`。或工具栏变「查看面试」→ 亦判 ok（此时 sourceKey 取该窗口最新一条出站 21130009 行；读不到行则回未确认）。零匹配 → `POSTCONDITION_UNCONFIRMED`、sideEffect possible、manualOnly → 脑验证读（1.1）→ suspect。

### 2. 必须立即阻断的损害

- **错靶**：目标绑定 + 最后一道闸核选中行=目标。
- **二次不可逆点击**：证词紧贴「发送」；前置读「查看面试」或已有出站 21130009 即拒；原语内不重试。
- **发错时间**：最后一道闸逐字核日期与时间 value 等于由 args 换算的期望；不合格参数干净失败不取整。
- **对真人发卡**（开发期）：交接日之后建档的会话才进沟通线；「已发卡不再邀面」闸在脑侧照旧。

### 3. 允许重试或人工兜底的失败

- 模态/下拉/日历未就绪、列表项滚不到、前台闸、标定 → 点「取消」后干净失败 retryable。
- 地址未配（onsite）→ `manualOnly`。
- 正证零匹配 → 未确认 → suspect 人工；绝不补动作。
