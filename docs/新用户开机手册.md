# 新用户开机手册

给新客户(新老师)的 Windows 电脑第一次开机部署用。照着顺序从上往下做,做完最后有一张检查清单,全部打勾才算完工。

## 开工前先备齐这些东西

| 物料 | 找谁要 | 用在哪一步 |
|---|---|---|
| 老师的智联账号(手机号,登录时老师配合收验证码) | 老师 | 一.2 |
| 老师本人微信号 | 老师 | 一.3 |
| 公司地址(准确到楼栋门牌) | 老师 | 一.4 |
| 客户端激活码(一次性) | 管理员 | 二.3 |
| Clash Verge 订阅链接 | 管理员 | 二.1 |

## 一、智联上号相关

### 1. 下载并安装 Chrome 浏览器

- 下载地址:<https://www.google.cn/chrome/>(国内可直接打开)。
- 安装后建议设为默认浏览器。
- 后面所有智联操作都在 Chrome 里做,软件的插件也装在 Chrome 里,别用 Edge 或其他浏览器代替。

### 2. 登录老师的智联账号

- 打开智联招聘,进入**招聘端**("我要招人"入口,不是找工作的求职端;招聘端工作台域名是 `rd6.zhaopin.com`)。
- 用老师的手机号 + 短信验证码登录,登录时联系老师配合转发验证码。
- 登录后**不要退出**,保持这个登录态,后面软件干活全靠它。

### 3. 个人中心里填微信号

- 在招聘端的个人中心 / 账号设置里找到微信号一栏,填**老师本人微信号**并保存(具体入口文案以页面实际为准)。
- 目的:候选人同意交换微信后,平台把这个号递给对方。这一栏空着,换微信环节走不通。

### 4. 发布一个测试职位(目的是存公司地址)

这一步只为一件事:**让智联把公司地址存进账号的地址库**,以后软件自动发布职位时直接选用。

- 随便新建一个职位,其他字段随便填,能通过发布就行。
- **唯一要认真填的是公司地址(工作地点)字段**:城市、区、街道逐级选对,详细地址写到楼栋门牌号,和老师确认无误再提交。
- 发布成功后,地址就已经被智联存下了。随后把这个测试职位**下架并删除**,不留在线上。

### 5. 联系老师完成认证

- 测试职位发布成功后,页面会弹出需要认证的提示(需要老师**本人**操作,通常是实名/人脸认证)。
- 联系老师完成认证即可。

## 二、软件安装

### 1. Clash Verge

- 用途:给电脑提供网络代理,AI 服务要靠它才连得上。
- 下载地址:<https://ybkc.oss-cn-beijing.aliyuncs.com/alytz/Clash.Verge_2.5.2_x64-setup.exe>
- 安装后:导入管理员提供的订阅链接 → 开启**系统代理** → 建议开启开机自启。
- 验证:浏览器能打开 `google.com` 即为通。

### 2. 向日葵

- 用途:我方远程协助与日常维护。
- 官网 <https://sunlogin.oray.com> 下载安装。
- 安装后**登录向日葵账号**,并在设置里把验证码改为**永久验证码**(不用每次临时生成)。
- 把本机的**识别码与永久验证码**发给我方,并建议开启开机自启,后续维护就不用客户在场配合。

### 3. AI增员助手客户端(并给 Chrome 加载插件)

**下载安装包**

- 下载地址:<http://8.153.161.25/rh-updates/pkg/RecruitHelper-3.0.2-setup.exe>

**安装**

- 双击安装包。首次运行 Windows SmartScreen 会拦截:点"更多信息" → "仍要运行"。
- 用户级安装,不需要管理员权限,装完桌面会有「AI增员助手」快捷方式。

**预埋杀毒排除(管理员 PowerShell,一次性)**

目的:防止 Windows 自带杀毒(Defender/MSRT)日后误删客户端主程序。装完客户端就做。

1. 右键开始菜单 → 选「终端(管理员)」或「Windows PowerShell(管理员)」,弹出的授权提示点"是";
2. 把下面整段命令一次性粘贴进去,回车执行:

   ```powershell
   reg add "HKLM\SOFTWARE\Policies\Microsoft\MRT" /v DontOfferThroughWUAU /t REG_DWORD /d 1 /f | Out-Null
   reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Exclusions\Paths" /v "$env:LOCALAPPDATA\Programs\RecruitHelper" /t REG_DWORD /d 0 /f | Out-Null
   reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Exclusions\Paths" /v "$env:LOCALAPPDATA\RecruitHelper" /t REG_DWORD /d 0 /f | Out-Null
   $brain = "$env:LOCALAPPDATA\Programs\RecruitHelper\resources\brain\RecruitHelperBrain.exe"
   "脑文件: " + $(if (Test-Path $brain) {"在位"} else {"缺失!需重装"})
   "MRT策略: " + (Get-ItemProperty "HKLM:\SOFTWARE\Policies\Microsoft\MRT").DontOfferThroughWUAU
   "策略排除: " + ((Get-Item "HKLM:\SOFTWARE\Policies\Microsoft\Windows Defender\Exclusions\Paths").Property -join " | ")
   "杀软: " + ((Get-CimInstance -Namespace root/SecurityCenter2 -ClassName AntiVirusProduct).displayName -join " | ")
   try {
     Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\Programs\RecruitHelper" -ErrorAction Stop
     Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\RecruitHelper" -ErrorAction Stop
     "本地排除: " + ((Get-MpPreference).ExclusionPath -join " | ")
   } catch { Write-Host "本地排除: 加不进去——Defender 服务未在运行(被禁用或第三方接管),策略排除已预埋兜底" -ForegroundColor Red }
   "本月MSRT: " + $(if (Test-Path C:\Windows\debug\mrt.log) { (Select-String -Path C:\Windows\debug\mrt.log -Pattern "Started On|Threat Detected|No infection" | Select-Object -Last 4 | ForEach-Object Line) -join " ;; " } else { "从未运行过(无日志,更安全)" })
   ```

3. 核对输出:`脑文件: 在位`、`MRT策略: 1`、`策略排除:` 列出两个 RecruitHelper 路径即为成功;`本地排除:` 若显示红字"加不进去"也不要紧,策略排除已经兜底。

**首次启动一次客户端**

- 装完先启动一次客户端再去装插件——客户端启动时才会把插件文件放到 Chrome 要读的固定目录。

**给 Chrome 加载插件(一次性)**

1. Chrome 地址栏输入 `chrome://extensions` 回车;
2. 打开右上角**开发者模式**开关;
3. 点**加载已解压的扩展程序**,在路径栏粘贴:

   ```
   %LOCALAPPDATA%\RecruitHelper\plugin
   ```

4. 确认扩展加载成功、处于启用状态。

**激活**

- 在客户端激活页输入管理员提供的一次性激活码,绑定本机。

**激活后重启一次客户端**

- 完整退出客户端(**托盘图标右键"退出"**,只点窗口关闭按钮不算退出)再重新启动——AI 模型连接要重启后才生效。首次装机这一步不能省。

**验证收工**

- 客户端里显示插件(手)在线;
- Chrome 保持登录智联招聘端;
- 在客户端点"开始"能正常进入工作流(业务运行窗口是每天 08:00–24:00,窗口外点不了属正常)。

## 常见问题

- **客户端某天突然打不开、或主程序文件消失**:大概率是 Windows 杀毒(Defender/MSRT)误删,不要自己反复重装,直接联系我方处理。
- **点"开始"提示"请先登录智联招聘端"**:说明 Chrome 里登录的是求职端或已掉线,回 `rd6.zhaopin.com` 重新登录招聘端。
